# Langbara

I was one of the contributors to **Langbara** project.

It was an educational app designed to make learning English fun and engaging. Developed as part of the "Zwolnieni z Teorii" contest, this project combines a robust backend with an intuitive frontend, providing both learners and educators with tools to enhance their language skills.

## Features

- **Interactive Learning:** Guess words from definitions, practice skills, and compete with others.
  
- **Convenience:** Learn in just a moment each day.

- **Engaging Experience:** Earn points, climb rankings, and expand your vocabulary while having fun.

- **Accessible Learning:** Suitable for all ages and knowledge levels. Learn English from home at no cost.

- **Built-in Authentication System:** Secure login system for both students and administrators.

## Getting Started

This section provides a quick overview to get the project up and running on your local machine.

### Prerequisites

Before you begin, ensure you have the following installed:

- [Docker](https://www.docker.com/)
- [Docker Compose](https://docs.docker.com/compose/)

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/langbara.git
   cd langbara
   ```

2. Build and start the application:
   ```bash
   docker-compose up --build
   ```

3. Access the application at `http://localhost:3000`.
